# AumCrawl – AI Crawler Control: See and Block AI Bots

See which AI crawlers actually read your site, and turn away the ones that take your content and never send a visitor back.

- **WordPress.org:** https://wordpress.org/plugins/aumcrawl/
- **Website:** https://aumcreate.com
- **Support:** support@aumcreate.com

## About this repository

This is the released source of the plugin, exactly as published on WordPress.org — one commit per release, tagged with the version. Bug reports and pull requests are welcome here; fixes are folded into the next release.

## Install

Install from the WordPress plugin directory (Plugins → Add New → search for *AumCrawl – AI Crawler Control: See and Block AI Bots*), or download a release from this repository's tags and upload the ZIP.
